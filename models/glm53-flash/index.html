04 / EVIDENCE

Zeus · TP4 × EP4

4 card / 16 rank / 32 core。Routed 使用 per-tensor FP8；Shared 为 BF16，仅 EP0 执行。每个 launch 取最慢 core，rank 内累加所有阶段，逐层取最慢 rank，最后累加 42 层。

tokens/s/card = 总 BS × 400,000,000 / cycles / 4

H200 · MoE TP1 × EP4

4 张 H200 NVL，每卡 72 个完整 Routed 专家；独立 FP8 Shared 跨四卡 TP4，每卡 I512。各层使用 rank 内测时样本中位数，取最慢 EP，再累加 42 层。

tokens/s/card = 总 BS × 1,000 / ms / 4

两侧都包含 MoE 计算与本地处理；排除通信、Attention、host 调度、JIT、数据与权重加载。激活采集拓扑为 TP4/EP1，执行拓扑分别记录，不能把采集拓扑当作测量拓扑。小 batch 是父激活前缀的组件回放，未重新运行对应 batch 的完整模型。

原有正确性门禁保持不变

Zeus 每个完成 case 均要求 Router/Shared 实现参考、Routed LUT 参考、Reduce exact、两次 Graph replay 与 changed-input Graph 检查通过，并核对 native 完成状态。解析数学参考另行记录：当前已完成完整档位有 0 个 case 超出原解析预算；这不等于原实现参考或 Graph 失败，预算没有放宽。

解析误差涉及量化、近似激活及归并边界，端到端影响由算法团队持续进行真实推理评估。用户已向算法团队确认，目前真实推理任务未观察到相应问题；该反馈不替代本页的组件精度记录，也不证明所有任务无影响。
